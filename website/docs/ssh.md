# Setting Up Remote Access 
## What is Remote Access?
Remote access allows you to control the Raspberry Pi from another computer, without the need for a dedicated monitor, mouse, and keyboard for the Raspberry Pi. 

## What is SSH?
It is a network protocol that lets you securely access other computers remotely on unsecured networks.
