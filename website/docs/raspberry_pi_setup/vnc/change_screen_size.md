# Change the Raspberry Pi Screen Size
If you want to make icons on the Raspberry Pi larger or smaller, follow this guide. 

1. Right click the top bar, or click the keyboard icon on the top right.
    <figure class="image-row">
        <div>
            <img src="{{ site.baseurl }}/assets/raspberry_pi_setup/boot/raspberry_pi/screen_size/Select_Keyboard_Icon.png" 
                alt="Image of a red box around the keyboard Icon">
            <figcaption>
                Click on this to open a menu for some settings.
            </figcaption>
        </div>
        <div>
            <img src="{{ site.baseurl }}/assets/raspberry_pi_setup/boot/raspberry_pi/screen_size/Select_Taskbar.png" 
                alt="Image of a red box around the taskbar menu">
            <figcaption>
                Right click on the taskbar to open the same menu.
            </figcaption>
        </div>
    </figure>

2. Select the "Taskbar Preferences" option in the menu that pops up. 
    <figure class="image-row">
        <div>
            <img src="{{ site.baseurl }}/assets/raspberry_pi_setup/boot/raspberry_pi/screen_size/Select_Taskbar_Preferences.png" 
                alt="Image of a red box around the Taskbar Preferences menu option from the keyboard icon menu">
            <figcaption>
                Click on this to open the taskbar settings.
            </figcaption>
        </div>
        <div>
            <img src="{{ site.baseurl }}/assets/raspberry_pi_setup/boot/raspberry_pi/screen_size/Select_Taskbar_Preferences1.png" 
                alt="Image of a red box around the Taskbar Preferences menu option from the taskbar menu">
            <figcaption>
                Click on this to open the taskbar settings.
            </figcaption>
        </div>
    </figure>

3. Select the "Defaults" tab. 
    <figure>
        <div>
            <img src="{{ site.baseurl }}/assets/raspberry_pi_setup/boot/raspberry_pi/screen_size/Select_Defaults.png" 
                alt="Image of a red box around the Defaults tab">
            <figcaption>
                Click on this to open the default options for the taskbar.
            </figcaption>
        </div>
    </figure>

4. Select the "Set Defaults" button that applies to you. Select Large Screens to make everything larger, and select small screens to make everything smaller. 
    <figure>
        <div>
            <img src="{{ site.baseurl }}/assets/raspberry_pi_setup/boot/raspberry_pi/screen_size/Select_Preference.png" 
                alt="Image of a red box around the three default screen size options">
            <figcaption>
                Click on one of these to change the text and icon size on your screen.
            </figcaption>
        </div>
    </figure>

5. Press "OK" to accept the changes.
    <figure>
        <div>
            <img src="{{ site.baseurl }}/assets/raspberry_pi_setup/boot/raspberry_pi/screen_size/Accept_Changes.png" 
                alt="Image of a red box around the OK button">
            <figcaption>
                Click on this to apply your changes.
            </figcaption>
        </div>
    </figure>
